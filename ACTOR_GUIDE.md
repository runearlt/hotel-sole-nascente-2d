# Hotel case and actor conversations

The hotel exercise follows `1. EN - Case.doc` (sections 1–4.1): **78 rooms**, prices in **DKK**, and Table 3 customer-group demand in **room-nights**. The bakery and winery are separately labelled, euro-priced game extensions; their quantities do not come from the original case. The source document's `TENTATIVE SOLUTIONS` section is excluded from actor context.

Students choose **Guided** or **Ask your own questions** at the start. Both modes use the same hotel case tasks, extension tasks, notebook, progress and reflection. Guided questions are in `public/app.js` (`Q`). The free-question role cards are in `public/free-agents.js`; edit `instruction`, `facts`, `match`, `say`, `solutionBoundary` and `scopePrompt` to tune each actor. Curated original-case background for the model is in `server/case-facts.js`. The hotel calculations and validation are in `public/case-hotel.js`.

With `OPENAI_API_KEY` set **on the server**, the free-question mode calls `POST /api/actor`. `server/actor-api.js` sends each actor's instructions, permitted case facts and recent conversation to the OpenAI Responses API. Student messages are treated as questions. Full-solution requests are blocked before the API call; model replies that contain obvious worked results fall back to approved facts. Model output is still nondeterministic, so a small real-student pilot remains necessary. Without a key, the endpoint replies using the deterministic fact matcher. The key must never be put in `public/` or committed to GitHub.

Local development: `npm ci`, then `npm start`. Open `http://localhost:8174`. To test model replies, supply `OPENAI_API_KEY` as a server environment variable. Run `npm test`, `npm run test:student`, and `npm run test:simulation`. The browser tests cover Guided and free-question modes at desktop and phone sizes. The 200 scripted playthroughs test the route and deliberately incorrect answers; they are not real students.

On Render, this bot needs a **Node web service** using `npm ci --omit=dev` and `npm start`, with `OPENAI_API_KEY` set as a secret environment variable. An existing Render static site cannot serve `/api/actor`; if only static hosting is available, the game uses deterministic fact replies. `render.yaml` describes a Node web service for a new deployment. Configure the model with `OPENAI_MODEL` if desired; the default is `gpt-5-mini`.
